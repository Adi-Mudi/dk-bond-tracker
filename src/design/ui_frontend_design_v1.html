7. Error State

wireframe: screen_error_state · ref FR-21
Error Statevisible surface for named errors
Error: named errors surface here — silent swallow forbidden (FR-21)
Example: DuplicateISINError — duplicate ISIN INE9000A01001 found across bond rows 2 and 14. Import aborted; no partial success committed.

No silent swallow — every failure surfaces on the page that triggered it. Flask error handlers render an explicit error page/message for unexpected route exceptions; import failures abort with a named error; an unresolvable current month shows an explicit message, never a silent 0.

Holds & constraints (from Final_Design_DK_Bond_Tracker_v1)

  • Hold L1 (OPEN — owner decision): import reconciliation acceptance waits on the owner re-baselining the PRD exit figures (workbook 28500.00 / -521500.00 vs PRD 28500.00 / -521500.00) and settling the Balance definition (L = K − J vs Investment − Till Return). TC-26 stays pending_baseline; never force-matched.
  • Hold L2 (OPEN — owner decision): P&L definition (Stage-7 proposal: Till Return − Investment; alternative: maturity − investment) awaits owner confirmation before FR-16 / TC-40 acceptance.

Offline / no-account note (D10)

  • Server binds 127.0.0.1 only; zero outbound network in any code path.
  • No accounts, sessions or auth layer; single local SQLite file is the sole persistence artifact.
  • Sharing means copying the folder — no cloud, no build step.
