4 · Lookup behavior (what changed)

How the ISIN lookup now behaves

  • Leaving the ISIN field starts the lookup in place — no page reload, no lost typing, no keyboard jump.
  • Answer order: bundled offline snapshot → published masters (NSDL/RBI/NSE/BSE) → live unofficial fallback. The 60s pacing countdown applies only to that last fallback; file downloads never pace.
  • Nothing found or source unreachable: one amber line, every field stays editable, no popup.
  • After Apply: an applied marker keeps the popup closed for that ISIN — reopening the page cannot bring it back while the applied values stand.

5 · Auto-fetch choice · model B refined

Ask once on first open — then it lives in Settings

First open (or first time lookup data is needed) — shown once, never again:

Fetch bond details automatically?

The app can refresh bond facts in the background when you open it (at most once every 12 hours). Nothing is fetched without your choice. You can change this later in Settings.

Not now = cancel: stored as the setting; zero background activity until you enable it in Settings. Auto-fetch: the 12h counter starts from this moment.

Settings → Data & sync (visible at all times):

ON: app open runs one pass only when the 12h window elapsed AND no per-ISIN cooldown is active AND known ISINs exist. OFF: zero background activity — ISIN lookup, per-ISIN refresh and Sync now stay fully manual. Last synced updates only after a real pass. Cooldown applies only to the official check (local answers are always instant).
