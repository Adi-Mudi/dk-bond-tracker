Component Breakdown & Layout Invariants

TOP APP BAR (56px)

Brand text DK Bond Tracker (bold 16px) left-aligned. Static icons right in locked order: Hide amounts (eye), Sync, Bell (badge 2), and Avatar (DK). Identical on every page.

• IDENTICAL on every page
• Page names NEVER appear in the bar
2

SEARCH & QUERY INPUT

Search inputs and filter chips live strictly inside Page Content (e.g. portfolio holdings filter row).

• Never placed in static top bar
• Scrolls with screen data
3

BOTTOM NAVIGATION (5 DESTINATIONS)

Exactly 5 destinations: Dashboard, Portfolio, Watchlist, Goals, More. Single primary navigation model.

• Active item = primary page indicator
• "More" triggers secondary system sheet
4

FLOATING ACTION BUTTON (56px)

56px circular button in #2456E6 with white plus icon. Fixed layout coordinates: right: 16px, bottom: 104px.

• Triggers "Add Bond" modal flow
• Same position across all 5 destinations
5

DYNAMIC CONTENT ZONE

The only zone that varies across screens. Content begins here with 16px standard page padding and 8px spatial grid.

• Section tabs & filter rows live here
• Tabular figures with font-variant-numeric
6

TOUCH TARGETS & STATUS ACCESSIBILITY

All interactive targets are sized ≥48×48px with 8px minimum spacing. Status pills are never color-only.

• Always paired with textual status label
• Minimum 4.5:1 contrast on dark surface
7

HIDE AMOUNTS — DEFAULT ON

All rupee amounts render HIDDEN by default (masked as ••••••). Tapping the eye icon reveals them; tapping again re-hides. User-friendly privacy across every page.

• Applies to KPIs, tables, cards, payouts
