SECTION C

BUSINESS RULES

Deterministic state machine constraints & credit-bound validations
01 // RATING GATE
Investment Grade Bound

Only bonds rated between AAA and BBB- can be introduced to active portfolios. Sub-investment grade bonds are rejected.

02 // DANGER STATUS
Any Unpaid Past Month

Evaluated across the entire historical timeline. If ANY past coupon date is unpaid, status flips to DANGER instantly.

03 // LIFECYCLE
Company-OR-ISIN Lock

Company-OR-ISIN lock: one active position per company or ISIN; unlocks on Completed status (not maturity-only).

04 // PAYMENT CYCLE
Tenure & Credit-Days

Tenure calculation adheres to strict market convention rules, adjusting for clearing holidays and scheduled credit intervals.

05 // REINVESTMENT
Principal Free-Up Report

Reinvestment = principal free-up report (grid readout), not allocation.

06 // PRIVACY MODE
Client-Side CSS/JS Class

Privacy mode = client-side .privacy-on CSS/JS class + share/print flag - server JSON masking NOT implemented (Flutter must decide masking layer).

07 // RECOMPUTATION
Instant Ledger Recalc

Every single payment mutation recalculates historical yields, portfolio totals, and cash flow projections dynamically in-memory.

08 // ERR GUARD
ERR-Entry Guard

ERR-entry guard: watch-only entry blocked from ledger (err guard).
