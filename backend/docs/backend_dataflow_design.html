LOCK-01 // WATCHLIST (STARTING POINT)

review board locked 2026-11-25. Single continuous ledger (no watch/held split). Notifications first: WATCHING + ALERTS stats + Rating Watch card. Company-first cards: [HELD] rows (units/completed/ongoing/settled) + [WATCH] rows (broker/yield/Move) + compare-brokers card.

LOCK-02 // ADD BOND FORM (hidden until FAB +)

Appears only after FAB + or the ADD FORM tab. First open = LEDGER tab + zeroed notifications + empty-ledger placeholder (EMPTY-STATE-FIRST). FAB on Dashboard/Portfolio/Watchlist all open this form.

LOCK-03 // MOVE TO PORTFOLIO

Inline confirmation (qty, amount, date, broker ref) + Link-to-Goal (select existing, Update goals, return with entries intact).

LOCK-04 // DELETE (buried)

Card -> Details -> overflow (vertical dots) -> Remove (red) -> type full ISIN + hold 2s. Watch candidates only; held positions NEVER deleted here. No front-facing delete button, ever.

LOCK-05 // PORTFOLIO (holdings + payout mobile)

holdings + payout boards locked 2026-11-24/25.

LOCK-06 // DASHBOARD (bar + sticky tabs + returns + cashflow calendar)

status engine + returns board + cashflow tab locked 2026-11-25.

LOCK-07 // GOALS BOARD

FAB opens the Goal form (in design). Goals + check-ins.

LOCK-08 // SETTINGS + ABOUT BOARDS

email test, auto-fetch consent/sync, import; about + semver updater.

LOCK-09 // APP FRAME (static shell)

brand bar -> sticky ADD FORM | LEDGER tabs -> content -> bottom nav -> FAB. Locked 2026-11-24.

Registry: frontend/confirmed/STITCH_LOCK_REGISTRY.json + INDEX v1.9. Starting point: Watchlist FAB + -> Add Bond form.

holdings rows + payout mobile calendar from payment_ledger.

goal board + check-ins from financial_goals.

email test, auto-fetch consent + 12h sync, import, semver check.

per-source cadences (NSDL weekly, BSE/NSE daily trading days, RSS daily) + alerts evaluation + staleness marking.

SECTION C

BUSINESS RULES

Deterministic state machine constraints & credit-bound validations
01RATING GATE
Official & Standing Feeds
Investment Grade Bound

Only bonds rated between AAA and BBB- can be introduced to active portfolios. Sub-investment grade bonds are rejected.

02 // DANGER STATUS
Any Unpaid Past Month

Danger = ANY unpaid past month, not just the previous one. Status recomputes the moment a payment changes.

03 // LIFECYCLE
Company-OR-ISIN Lock

One active position per company or ISIN; unlocks on Completed status. ERR-entry guard: watch-only entry blocked from ledger.

04 // PAYMENT CYCLEproposed target - pending T2
Tenure & Credit-Days

Tenure calculation adheres to strict market convention rules, per the bond credit-day setting (holiday calendar source: TBD).

05 // REINVESTMENT
Principal Free-Up Report

Reinvestment = principal free-up report (grid readout), not allocation.

06 // PRIVACY MODE
Client-Side CSS/JS Class

Privacy mode = client-side .privacy-on CSS/JS class + share/print flag - server JSON masking NOT implemented (Flutter must decide masking layer).

07 // RECOMPUTATION
Instant Ledger Recalc

Every single payment mutation recalculates historical yields, portfolio totals, and cash flow projections dynamically in-memory.

08 // ERR GUARD
ERR-Entry Guard

ERR-entry guard: watch-only entry blocked from ledger (err guard).
