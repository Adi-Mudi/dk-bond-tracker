Add Position — exact dates + credit day (new in v3: D26 / FR-36)

Start date · End date → tenure auto-calculated · Payment credit day (1-28)
Example: 03-Sep-2025 → 02-Dec-2026 → Tenure: 15 months (auto)

No manual tenure entry: tenure months are computed from the start/end range. The credit day drives the day-wise sweep (D22) and all alert timing; legacy import maps start month → start date, tenure → computed end date, default credit day = start date’s day (TC-83).

Blocked — active-position lock (D15 / FR-26)
Cannot add position: Beta Finance has an active position (On-going) — no override
Match key: normalized company name (trim/case-insensitive) OR ISIN — a duplicate is blocked while the existing position is On-going or Danger. Hard block with named error (FR-21): no override, no force.
Released when Completed
The lock releases only when the existing position reaches Completed (D5: months paid >= tenure). A new position bought after Completed starts On-going and re-locks the company until it too completes.

No override anywhere — the same named error also surfaces on the Error State screen (FR-21).

Offline / no-account note (D10)

  • Server binds 127.0.0.1 only; zero outbound network in any code path.
  • No accounts, sessions or auth layer; single local SQLite file is the sole persistence artifact.
  • Sharing means copying the folder — no cloud, no build step.
