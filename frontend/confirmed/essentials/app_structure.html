4 · Structure rules (Essential 0.5–0.22 — E0 audit additions)

Rule (0.x)Contract statement
0.5 Layer directionui/ → data/ → pure helpers (shared/utils) — UI may import data; data may import pure helpers; helpers contain NO network/storage code; no layer imports from a layer above it.
0.6 Feature isolationA feature never imports another feature's internals — features/<a> ↛ features/<b>. Removing one feature folder must break nothing elsewhere. Cross-feature sharing goes through shared/ only. Enforcement: CI import-boundary check blocks the merge (scripts/check_flutter_imports.sh + .github/workflows/flutter.yml).
0.9–0.11 NamingOne convention project-wide: snake_case files named after responsibility (role, not how) — enforced by flutter_lints file_names + CI flutter analyze; a whole folder in another style is forbidden (no directory-level exceptions).
0.12 AliasesStable import root = package:app/… (pubspec name) — one alias, used everywhere; moved files change nothing for importers inside the package.
0.16 Folder purposeslib/features/ = one folder per page/feature (ui+data+index) · lib/shared/ = cross-feature only (widgets = kit, utils = pure helpers, theme = tokens) · lib/config/ = app configuration constants · assets/ = static media/fonts · test/ = Flutter tests · root = pubspec + analysis_options + platform runner. Anything matching no purpose waits for a decision record.
0.19 New top-level folderAdding a top-level folder under frontend/app/ (or lib/) = structural decision: written record (purpose, owner, why no fit) committed BEFORE creation — same gate as DOC.13.
0.21 MigrationRenames/moves: files moved + ALL imports updated + decision logged in the same change — nothing silently deleted from version history.
0.22 Shared growth watchlib/shared/ growth triggers review (see app-essential-elements audit cadence + E16 adoption watch) — unbounded growth = feature leakage; growth triggers a decision, never default acceptance.
0.8 / 0.20 Reserved dirsui/ , data/ , assets/ are reserved-until-populated: created with their FIRST real file (DOC.14 — no empty placeholders; scaffold intentionally ships only <name>.dart index files).
0.17 EnforcementImport-direction + boundary rules live here and are machine-checked by CI (.github/workflows/flutter.yml: flutter analyze + flutter test + import-boundary script) — illegal imports block merge. Local pre-commit Flutter check = future addendum (global hook is workshop-managed).
