Locked global rules (hard constraints on every generation)

  • No target amounts on reading surfaces — cards/detail/stats never show ₹20,00,000 or %-of-target; the Target input exists only in Create Form
  • Progress = months, exactly one signal — on plan: "X/Y months ✓" (green) · any miss: "N months missed" (red) — negative wins and stays until resolved
  • Rhythm rows show invested AND returns — e.g. "✓ ₹35,000 invested · +₹1,820 returns"; MISSED months still show returns (motivation)
  • Goals have no Remove — menus = Edit goal · Archive goal only; goals end via Achieved or Archived
  • ₹ INR only · Compact-only MVP (412dp) · skeleton loading for lists · no asterisks on labels · one label per concept (Save goal / Record check-in / Save draft / Archive goal)
