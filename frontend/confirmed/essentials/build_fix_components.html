Specimen 01

TOAST / SNACKBAR

Duration: 3–5s · Fixed Viewport Anchored
(a) Standard Confirmation Auto-dismiss 3s
Payment saved

Dispatches on non-blocking write completion. Zero user intervention required.

(b) Destructive Reversible Auto-dismiss 5s
Entry removed

Preserves 5-second undo buffer in local memory before committing database purge.

(c) Antipattern Callout NEVER-TOAST-FOR-ERROR
Could not save: no connection

Flagged rule: transient toasts must never hide critical failures. System errors require persistent inline banners.

CAPTION: one line, 3–5s, specific words.
Specimen 02

SUBMIT-LOCK BUTTON (Single-Action Lock)

Latency Target: ≤0.1s Feedback
State 1: Idle Primary Enabled

Explicit amount in label eliminates ambiguity before commitment.

State 2: Pressed Active Touch

Immediate visual feedback (scale down + dim) triggered <100ms on tap down.

State 3: Disabled + Spinner Lock Engaged

Pointer-events zeroed. Prevents multi-click duplicate network dispatches.

CAPTION: one tap = one action, feedback ≤0.1s.
