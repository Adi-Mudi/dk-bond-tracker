Interactivity

  • • Gestures (page contract): tap-only · NO swipe-delete (delete buried behind typed-ISIN + hold) · system edge=back WINS over in-app gestures · W4 hold-2s is the ONLY long-press (confirm gate)

Q3 STATES — all four + loading pattern

Life Cycle
  • • Working ✓: live ledger · Rating Watch + "Maturing in N days" are WORKING business states (not errors) · zeroed first-open stats "0 nothing yet / 0 • all clear" (G1) · COMING SOON disabled (C9) · Value per unit "—" when missing (C12)
  • • Loading: SKELETON for ledger rows (W10/H1) · SPINNER "Checking" for ISIN fetch only (one-off, no known layout) · Save/Move button = inline spinner + submit lock · sync icon spins until refresh done/error (H7) · Load More = loading(more) (W11)
  • • Empty ✓: "No bonds yet — Add first bond" (G2)
  • • Error ✓: persistent error strip + Retry for ledger load / save / move / remove (H2) · entry preserved on failed save/move (H2/H6) · duplicate-ISIN banner · fetch Not Found (C3) · Offline copy · rating-gate refusal ERR-watch-rating-gate "only AAA to BBB- … cannot be added" (watch.py:152-155, 553, 833) · Load More error → retry (W11)
  • • Rule: skeleton never replaced by spinner when layout is known

Q4 SCROLL — three answers

Viewport Behavior
  • • Load more: show-all at MVP scale; when >100 rows → Load More button (H4/W11, predictable pagination) · NEVER infinite scroll (footer + NSDL must stay reachable)
  • • Sticky: top app bar always · ADD FORM|LEDGER tabs sticky above scroll viewport · fixed bottom nav (E2, List frame only) · fixed Detail top bar (W12) · stat strip scrolls (not sticky)
  • • Scroll-to-top: floating TOP button appears after >1 screen (H3/W14) · short list (<1 screen) = TOP never renders · tap → smooth return to top
