3 · Per-feature detail (user does X → outcome Y) 47

Each feature as a testable sentence, with the components it is built from. Merge/split notes mark checkpoint2/3 rulings.

A · App shell (every frame) 5

  1. User sees the top bar → brand + sync + notifications(badge) + avatar, all tappable (4 separate controls — not one bundle)
  2. User taps ADD FORM / LEDGER tabs → the form pane or ledger pane switches with live counts (same segmented widget as G1 first-open default)
  3. User reads the stat strip → WATCHING active count + ALERTS sub-line update live
  4. User taps a bottom-nav tab → switches root (Watchlist active here; per-tab stacks preserved)
  5. User taps FAB+ → Add Bond form opens ONE FAB widget, two rules: A5 shell semantics + G3 page semantics — merged (not2 components)

B · Notifications 2

  1. User sees a Rating Watch card → Critical severity chip + advisory text render (B2 actions are this card's action row — not a standalone feature)
  2. User taps Read Advisory / Dismiss → advisory opens / alert dismisses (action row of B1)

C · Column 01 — Add Bond form 14

  1. User taps FAB+ → form appears hidden-until-open (same hidden-form semantics as G1 first-open — merged)
  2. User types an ISIN and taps Fetch → NSDL/BSE lookup runs
  3. User watches Fetch → one of4 states shows: Found · Checking · Offline · Not Found
  4. User submits a duplicate → error banner blocks it, names the existing broker, suggests alternatives
  5. User reads Section A Identity → Company/ISIN/Rating/Agency appear auto (ISIN locked chip immutable)
  6. User reads Section B Economics → Coupon/Face/Payout auto, Expected Yield you-enter, auto/you-enter chips show provenance
  7. User reads Section C Terms → Issuer/Listing/Maturity show as readonly auto text (locked Col01 truth — old select/date specs retired)
  8. User sees Interest Credit Day → readonly auto field + helper (locked Col01+manifest AUTO — old numeric-input spec retired)
  9. User sees Default History → disabled auto field + COMING SOON chip + single defaulted ISIN = HIGHER RISK rule
  10. User reads Secured NCD → checkbox + "asset-backed senior claim" helper (locked Col01 checkbox — old display-field spec retired)
  11. User fills Section D Targets → Target Invested + Planned Quantity empty by design
  12. User fills both targets → value per unit computes live (em-dash until both present)
  13. User types a broker → typeahead suggests GoldenPi/Grip/IndiaBonds/Zerodha + free text
  14. User completes form (three parts, testable separately: source note optional · Save button · field chips) → bond saves to Watchlist

D · Column 02 — Integrated ledger 8

  1. User opens LEDGER → company-first merged list (Held+Watch, no tabs) — D2/D3 are its sub-elements, not standalone features
  2. User reads each row's pill →4-tier status: Danger > Maturing > On-going > Matured (sub-element of D1)
  3. User reads the header → total invested + "N bonds / X completed / Y ongoing" counts (sub-element of D1)
  4. User reviews [HELD] rows → ISIN, units, settled amount or "Maturing in N days" countdown
  5. User reviews [WATCH] rows → broker/cycle/yield + Move to Portfolio + Details taps
  6. User compares brokers → same ISIN at3 brokers, Best Yield tag, Select to pick one
  7. User reads the buy-step hint → "Buy at your broker first, then return here" guidance (10px hint inside D6 — sub-element, not standalone)
  8. User taps Browse NSDL → depository list opens (destination: OPEN — flagged)

E · Column 03 — Move to Portfolio 4

  1. User fills the conversion form → Quantity · Amount · Date · Broker Ref (all empty until typed)
  2. User optionally links a goal → picks one of the existing goals
  3. User taps Update goals → detour leaves and returns with entries intact
  4. User taps Confirm Move (Cancel aborts) → verified against depository sync → row becomes On-going

F · Column 04 — Remove flow 4

  1. User follows the buried chain Details → ⋮ → sheet → guarded modal → delete requires the full path (F4 = architecture rule enforced by F1/F3, not standalone)
  2. User opens the bottom sheet → View history · Edit target · Share prospectus · Remove(red) — destinations for the first3 = OPEN (flagged)
  3. User types the full ISIN and holds2s → guarded confirm fires; "held positions never deleted here" holds
  4. User reads the guard note → delete stays buried + watchlist-only (rule of F1/F3)

G · Column 05 — First open 3

  1. User opens Watchlist first time → LEDGER tab default, form hidden, zeroed stats ("0 nothing yet / 0 all clear") — hidden-form semantics shared with C1 (merged)
  2. User sees the empty state → headline + "Add first bond" CTA
  3. User taps FAB on any page → Dashboard/Portfolio/Watchlist + opens Add Bond; Goals + opens Goal form (G3 = page semantics of the ONE FAB — see A5)

H · States, scroll & shell behaviour 7

  1. User opens the ledger while loading → skeleton rows show the card layout (never a blank page)
  2. User hits a save/move/load failure → persistent specific error + Retry appears; typed entries preserved (never cleared)
  3. User scrolls past one screen → TOP (scroll-to-top) button appears; tap returns to top
  4. User passes100 rows → Load More button appends the next page (predictable pagination, footer reachable)
  5. User views the list → rows sort4-tier: Danger → Maturing → On-going → Matured (manifest order)
  6. User backs out (sheet X/system back/arrow_back/Cancel) → form entries preserved; cancel exits cleanly
  7. User taps sync → manual refresh runs; skeleton/states re-evaluate (drives H1/H2)
