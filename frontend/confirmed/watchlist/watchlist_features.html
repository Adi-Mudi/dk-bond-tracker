MVP split — 31 ship first · 10 fast-follow 41

MVP = the core loop only: add a bond → see it in the ledger → convert to portfolio (or remove), backed by what the existing backend already supports (watch form, credit_day, alerts). Post-MVP = convenience, edge cases and cross-feature integrations.

  • A1–A5 · App shell all 5: top bar, tabs, stat strip, bottom nav, FAB
  • C1–C8, C10–C12 · Add form hidden-on-open, ISIN lookup+fetch, 3 fetch states, dup error, Identity/Economics/Terms auto fields, Interest Credit Day, Secured NCD, Targets, value-per-unit math
  • C13a + C14b · Free-text broker entry · Save + auto/"you enter" chips
  • D1–D5 · Integrated ledger company-first view, 4-tier status pill, header counts, [HELD] rows, [WATCH] rows with Move + Details

  • F1–F4 · Guarded delete full approved 4-step flow — delete must exist even at low frequency
  • G1–G3 · First-open LEDGER-first behavior, empty placeholder + CTA, FAB page semantics
