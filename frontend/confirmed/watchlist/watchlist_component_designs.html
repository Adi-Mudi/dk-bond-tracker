Rules that apply to every component global

GESTURE RULES (per component, must be stated): Watchlist page is tap-only — no swipe-delete anywhere (single accidental swipe must never act; delete is buried behind typed-ISIN + hold-2s) · W4 Hold-2s Confirm is the ONLY long-press on this page (confirm gate) · any edge swipe = system back wins · NO horizontal scroll anywhere on this page (Multi-Broker Compare is a vertical stack of 3 rows — never a horizontal table) · every gesture conflict listed in that component's ACTIONS row.
NESTING RULE: components nest — each level runs its own checklist. The page never talks to the database — only to its own components. Data flows: store/endpoint → page/repository → props down → components; events flow: component callback → page → repository. Nesting map: List screen (shell static on EVERY frame — brand bar + tabs + nav + FAB never hide; the Add Bond form is a PANE inside content, not a full-screen frame, per navigation_flow:3) ⊃ Top Bar(E1 ⊃ E20 badge) + Stat strip(E4) + Segmented tabs(KIT33) + Alert cards(KIT27 ⊃ KIT19 severity) + Company Card(W1) ⊃ Status Pill(E13) + Nested Rows(W2 ×n) + Callouts(KIT31) + Multi-Broker(W3 ⊃ E17 radio + W8 chip) + Load More(W11) + Empty State(E12, first-open G2) + FAB + Bottom Nav(E2) + TOP(W14) · Form pane ⊃ Text Inputs(E9) + Auto/You-Enter chips(W6) + COMING SOON(W7) + Locked ISIN(W15) + Value read-out(KIT9) + Secured checkbox(E16) + Suggestion chips(W13) + Fetch states(W5) + Banner(E11, dup-ISIN + fetch errors) + Save(E8) · Bond Detail route ⊃ Detail Header(W12 = E1 back-variant) + Overflow(E10) + Remove flow(KIT36 dialog ⊃ W4 hold-gate) + Callout(KIT31, Guarded note) · Move panel ⊃ Move Context Card(W9) + Inputs(E9) + Goal select(E9) + Callout(KIT31, Broker Record note) + Confirm/Cancel(E8). Reconciliation: board Col 01–05 each render the full static shell (goals-style full-screen-form-hides-nav does NOT apply here — form is a pane, tabs/nav stay).
