    Data sources

    Instrument facts are fetched from these public sources, then cached locally. Every fetched value keeps its source and fetch time, and the form never blocks when a source is unreachable.

    • NSDL Corporate bond master and the detailed ISIN search (primary source). Published download files - terms of use apply, no automated scraping.
    • RBI Outstanding Government Securities, State Development Loans and T-Bills. Published download files - RBI disclaimer applies.
    • NSE Debt security master. Published download files only - the NSE Terms of Use ban automated site or API collection.
    • BSE Debt segment security master. Published download files - BSE disclaimer applies.
    • india-isin-data Bundled offline ISIN snapshot that seeds a fresh install. CC0 1.0 (public domain).https://github.com/captn3m0/india-isin-data

    Bundled india-isin-data snapshot: v2026.11.12 (46715 securities) so a fresh install answers common ISINs with no network.

    Updating from a debug-signed install

    Releases are signed with a stable release certificate, so updates install in place. If you installed a debug build before, move your data once:

    1. In Settings, open Backup and restore and download the backup CSV.
    2. Uninstall the app.
    3. Install the new release APK.
    4. In Settings, open Backup and restore, choose the backup CSV and restore it.

    Why bonds?

    Fixed, predictable returns. That is what bonds are for — you know the coupon and the schedule up front. The share market can move a lot in either direction; bonds do not promise equity-level gains and are not built for them.

    Expectation check: if you are looking for more than roughly 10–12% returns, that is the share market's territory — not bonds. Choose bonds for fixed returns; choose equity only if you accept its risk for higher expectations.
    Flip side: if you have been putting daily effort into shares and still are not beating 10–12% — or you are losing — bonds deserve a serious look. Fixed returns, and you only need to analyse a few things once, not watch the market every day.
