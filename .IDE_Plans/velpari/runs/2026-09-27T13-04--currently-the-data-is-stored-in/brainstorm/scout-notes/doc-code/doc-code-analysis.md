## 3. VBA architecture (verified from olevba full dump, 747 lines)

1. **ThisWorkbook.cls** — Workbook_Open and Workbook_BeforeSave both run
   FixBondDashboard + InitializeMonthlyReturnsFormatting under `On Error Resume Next`.
2. **Sheet2 code (Monthly Returns)** — Worksheet_Change fires FormatRowPaymentTracking
   when column H (tenure), M (start month) or >=14 (month cells) change; uses only the
   Target anchor row; ScreenUpdating toggled manually, errors swallowed.
3. **Module1 (Dashboard builder)** — FixBondDashboard: turns off calc/events, creates
   Dashboard sheet if missing, rebuilds it (ClearDashboard A10:J1000 + full L:M clear,
   headers, summary formulas, status overview via bubble-sort, history table, formatting),
   then MsgBox "Dashboard has been restored and updated successfully!" on EVERY open/save
   (plus error MsgBox on failure). ErrorHandler MsgBox + Resume CleanUp.
4. **Module2 (Monthly Returns builder)** — InitializeMonthlyReturnsFormatting runs under
   `On Error Resume Next` (silently swallows failures): RegenerateMonthlyHeaders,
   FormatDateColumns, ApplyFormattingToAllRows, InjectFormulas (K/L columns).
5. **Dead code** — Module1 contains a second `Private Sub Workbook_Open` (standard module:
   never fires) and `AddWorksheetChangeEvent` which only re-runs FixBondDashboard (name
   promises an event handler, adds none). Sheet1.cls (Dashboard) is empty.

## 4. Quirks / risks (all verified in current VBA text)

1. Header regeneration is HARDCODED: RegenerateMonthlyHeaders writes Sep-2025..Feb-2027
   (cols 14-31) only. Headers Mar-2027..Jul-2032 (cols 32-96) are user-maintained.
2. FindStartingMonthColumn scans cols 14..78 (through Jan-2031) — a bond starting
   Feb-2031+ silently gets no formatting/status. Loop bound vs existing headers mismatch.
3. ClearRowFormatting resets cols 14..100 but does NOT reset NumberFormat — rupee formats
   linger outside the active window (observed: row 2 AF..AP still rupee-formatted after
   window ends at AE). Cells CS..CV (97-100, beyond headers) get style-only residue.
4. Status logic: "Danger" only if the PREVIOUS calendar month's cell is empty/0 (single
   month); older missed payments stay invisible. "Completed" (paymentsMade >= tenure)
   overrides Danger. Zero-value entry counts as unpaid.
5. Dashboard status overview rows 10+ are static values — stale between open/save events.
6. ApplyDashboardFormatting grows column widths E and H:J by +2 chars on EVERY open/save
   (accumulating drift).
7. E6 "This Month Returns" falls back to static 0 when current month header not found;
   ClearDashboard wipes entire Dashboard L:M columns every run.
8. Whole flow runs under On Error Resume Next in places — failures are silent (user only
   sees wrong/blank output).
9. CF duplicate-ISIN highlight only covers D7 and D14:D16 on Monthly Returns (partial).
10. Cross-sheet coupling is by header text Find ("Maturity Date") and positional columns —
    renaming a header silently changes behavior (default col 9).
11. MsgBox on every open/save blocks headless/bulk processing; EnableEvents toggling
    without cancellation handling can leave events disabled if Excel kills a dialog.
12. Workbook.Open flow depends on macro-enabled format (.xlsm); any xlsx/CSV/DB export
    loses all behavior (dashboard, status, coloring) unless reimplemented.
