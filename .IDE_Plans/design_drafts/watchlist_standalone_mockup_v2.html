Design notes (mockup v2 — screen-only)
  • Standalone shell: fake native window chrome (titlebar, menu, window buttons), collapsible-look sidebar, bottom status bar — app, not website.
  • 2-view watchlist: My Holdings (owned, 8) and Watching (candidates, 4) via segmented pill switcher.
  • New fields surfaced in table: Credit Rating badge (with agency), expected Yield %, Payout cycle tag, Next Payout amount, maturity countdown chips.
  • Alerts rail: overdue, due-soon and maturity-approaching cards, dismissible; red dots on affected table rows.
  • Settings: SMTP + alert prefs + general + data + about; credentials local-only, masked.
  • Offline honesty: ratings/yields/prices are entered manually; no live feed; connection chip shows Offline — local database; returns are ledger-computed.
  • Dark fintech theme, dense 40px rows, sticky header, right-aligned Indian-format money, status token colors preserved (Danger / On-going / Completed).
